# 行测计时 1.0.1

一个离线的安卓行测计时工具。支持 Android 8.0 及以上，适配手机、平板和横竖屏。无需账号、无需联网，无广告。

## 安装

将「行测计时-v1.0.1.apk」发送到安卓设备，在文件管理器中打开，按系统提示允许该来源安装，然后安装。

## 使用

1. 点击「120 分钟 · 设置」：选择 120/90 分钟，或输入 6–600 分钟的总时长。更改总时长会按比例分配模块时间，之后可分别调整六个模块的目标分钟数；六项之和须等于总时长。
2. 选择政治理论、常识判断、言语理解、数量关系、判断推理或资料分析，点击「开始计时」。
3. 点击其他模块立即切换。每个模块独立累计用时，切回来会继续累计；总计时不因切换中断。中央显示总剩余，下方显示当前模块剩余，模块卡片显示已用时间。
4. 点击「暂停计时」/「继续计时」。暂停时间不计入用时；计时运行且应用显示在前台时，屏幕保持常亮。
5. 点击「结束并保存」，应用先暂停，再填写可选名称并保存。记录页可打开任一次练习，查看各模块用时、占比及扇形图；统计页查看全部记录的平均用时扇形图。

## 计时与数据规则

- 时间格式统一为「分:秒」，例如 120:00 表示 120 分钟。
- 总时长或当前模块到时会发出提示音（受设备通知音量和静音设置影响），继续记录超时，不自动结束。
- 运行中的计时由安卓单调时钟计算，不受修改系统日期时间影响。切换应用、旋转屏幕或同一次开机内重新打开应用，恢复时会继续累计当前模块。
- 正在计时的数据每 5 秒保存，切换/暂停等操作立即保存。设备重启后，从最后一次保存的进度以暂停状态恢复，关机时间不补计。
- 平均用时 = 各模块累计用时 ÷ 全部已保存记录数量；某次未练习的模块按 0 计入。图中占比基于原始毫秒计算，显示的分钟秒数取整。
- 所有数据保存在应用私有的本地存储，不上传。卸载或清除应用数据会删除记录。删除单条历史记录须确认，删除后平均统计同步更新。
